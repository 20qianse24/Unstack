# Unstack

**A flexible, offline-first task manager built as a Progressive Web App (PWA).**

Unstack is a lightweight task management app designed to help you organise your to-do list without rigid workflows. Group tasks, rank them by priority, add notes, and reorder tasks to suit the way you work.

🌐 **Live app:** [20qianse24.github.io/Unstack](https://20qianse24.github.io/Unstack/)

## ✨ Features

- **Task management** — Create, edit, and delete tasks.
- **Priority-based organisation** — Assign priority labels to tasks and organise them into priority levels, with numbering to indicate their relative order.
- **Custom task groups** — Create your own groups to organise tasks by category, project, or context.
- **Task descriptions and notes** — Add optional longer descriptions to keep relevant information alongside each task.
- **Drag-and-drop reordering** — Rearrange tasks to reflect changing priorities and preferences.
- **Search and filtering** — Find tasks using the search bar and available filters.
- **Offline support** — Access the app without an internet connection after it has been loaded and cached.
- **Local data storage** — Keep task data on your device without requiring an account.
- **Installable PWA** — Add Unstack to your mobile home screen for an app-like experience without downloading it from an app store.

## 📱 Installation

Unstack runs directly in your browser, but you can install it on your phone as a Progressive Web App (PWA) for convenient access from your home screen and a native-app-like experience!

### iPhone and iPad (iOS)

1. Open [Unstack](https://20qianse24.github.io/Unstack/) in **Safari**.
2. Tap the **Share** button.
3. Scroll down and select **Add to Home Screen**.
4. Edit the name if desired, then tap **Add**.
5. Open Unstack from the new icon on your home screen.

> Installation through Safari is recommended on iOS. The option may not be available when opening the site in an in-app browser.

### Android

1. Open [Unstack](https://20qianse24.github.io/Unstack/) in **Chrome**.
2. Tap the three-dot menu in the top-right corner.
3. Select **Install app** or **Add to Home screen
